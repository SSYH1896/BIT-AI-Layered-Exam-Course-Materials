## 🔑 核心知识点

### 人工智能基础
- 人工智能的定义、三次发展浪潮、核心能力
- 符号主义、联结主义、行为主义三大流派
- AI应用场景与技术风险

### 神经网络与深度学习
- 感知机、MLP、CNN、RNN/LSTM/GNN
- Transformer与自注意力机制
- 位置编码、多头注意力

### AI Agent
- Agent定义与架构
- 与普通聊天机器人的区别
- 工具调用、规划与反馈

### 多模态AI
- 模态对齐与融合
- CLIP、GPT-4V等典型模型
- 应用场景与挑战

### 大语言模型
- 预训练与对齐技术
- 幻觉问题与缓解策略（RAG）
- 上下文学习、Chain-of-Thought

### PyTorch编程要点
- `model.train()` / `model.eval()` 模式切换
- Dropout与BatchNorm行为差异
- CNN参数与尺寸计算

## 📝 复习建议

1. **优先掌握样例试卷的8道题**：样例试卷直接反映正式考试的题型、难度和答题方式
2. **围绕官方考察重点复习**：基础理论、前沿技术、PyTorch编程
3. **准备2~3个通用案例**：如人脸识别/推荐系统的局限、医疗多模态诊断、Agent应用等
4. **熟悉CNN尺寸推导**：掌握卷积、池化后特征图尺寸变化
5. **控制答题节奏**：简答题200~300字，编程题注意状态切换
